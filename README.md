# 🍔 Food Delivery Dashboard – Excel Project
Interactive Food Delivery Dashboard built in Microsoft Excel using Pivot Tables, Pivot Charts, Slicers, and data analysis techniques to visualize key business insights and performance metrics.

## 📌 Project Overview

This project is an interactive **Food Delivery Dashboard** created using Microsoft Excel. The dashboard analyzes food delivery data and presents important business insights through interactive charts, Pivot Tables, and visual reports.

## 🛠️ Tools & Skills Used

* Microsoft Excel
* Advanced Excel
* Data Cleaning
* Data Analysis
* Pivot Tables
* Pivot Charts
* Slicers & Filters
* Dashboard Designing
* Data Visualization

## 📊 Dashboard Features

* Interactive Excel Dashboard
* Multiple Pivot Tables for data analysis
* Dynamic charts and visualizations
* Slicers for interactive filtering
* Easy-to-understand business insights
* Organized report and dashboard sheets

## 📁 Workbook Structure

The Excel workbook contains separate sheets for:

* Raw/Dataset
* Data Processing
* Analysis
* Reports
* Dashboard

## 🎯 Project Objective

The objective of this project is to transform raw food delivery data into an interactive dashboard that helps users understand trends, compare performance, and make data-driven decisions.

## 💡 Key Learning

Through this project, I practiced data cleaning, Pivot Table analysis, interactive dashboard creation, and presenting complex data in a simple and visually understandable format using Excel.
